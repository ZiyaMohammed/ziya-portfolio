# Ziya portfolio

A static site: no build step.

```
index.html      page markup (Home, Work, About, Case study)
css/style.css   all styles and themes
js/main.js      projects data, case-study content, interactions
img/ fonts/ logos/
```

Preview: in VS Code, click **Go Live** (Live Server extension), or open `index.html` in a browser.

Case-study content lives in `js/main.js`, in the `P` array near the top. Each project has an `id`, card details, and its story.
